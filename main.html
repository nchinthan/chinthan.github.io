01 / About

Curiosity is my starting point.

I'm a Computer Science student at the National Institute of Technology Durgapur, drawn to the engineering behind useful software. I like understanding a problem as a system: its data structures, interfaces, constraints, failure modes, and the trade-offs that shape a good solution.

01 / Developer tooling

ContextPruner

Token-Efficient AI Coding & Controlled Code Editing

A hierarchical context-selection workflow that lets developers choose exactly which files, classes, and methods an AI coding tool receives—rather than sending entire repositories.

  • Language-agnostic TreeNode model with an extension-based parser registry.
  • PromptTree for reusable, hierarchical instructions and code context.
  • Post-edit diff inspection to catch changes outside the intended scope.

02 / Knowledge systems

Personal Knowledge Engine

A self-hosted, AI-augmented note system

A personal knowledge base built around a Linux-inode-inspired storage engine, hierarchical notes, and a conversational retrieval pipeline.

  • Page retrieval and hash-based chunk tracking to reduce write amplification.
  • RAG pipeline that vectorizes hierarchical notes on write.
  • Radix Tree metadata lookup, MinHash, and k-shingling LSH deduplication.
PythonRAGRadix TreeMinHash / LSH

Personal Music Player & Recommendation Engine

A full-stack local music player with URL-to-audio conversion, metadata ingestion, and a low-latency chunk-based streaming backend.
